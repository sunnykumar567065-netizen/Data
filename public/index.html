Only configured response fields are returned.

GET /v1/lookup?q=DEMO-1001
X-API-Key: wg_your_generated_key
Response will appear here.
Default configuration searches exact values in the MOBILE field and returns MOBILE only. To change fields, set LOOKUP_FIELD and RESPONSE_FIELDS as Render environment variables, and redeploy. Avoid exposing personal or sensitive data through public endpoints.

Response behavior

200 exact match found · 400 missing query · 401 missing/invalid/expired key · 404 record not found · 429 quota reached or rate limit exceeded.

Not found responses include the configured fallback labels: @CoderArjun, @Tg_ownner and @ZAD_OSINT_EXPLOIT_OWNER. Labels are informational and do not identify a data owner.
